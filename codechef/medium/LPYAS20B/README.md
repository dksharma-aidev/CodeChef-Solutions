## Problem

### Print Pattern

Write a program to output the square of * (stars) of size 4 (check the output below).

```
  
  
  
   

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-07-25T07:21:17.713Z  

```py
# cook your dish here
i = 0
n = "*"
while i < 4:
    print(n * 4)
    i = i + 1
```
